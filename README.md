# 个人作品集网站

基于原生 HTML / CSS / JavaScript 的个人作品集单页网站，用于展示自我简介、技能清单与项目案例。

## 功能特性

- **项目案例展示**：图文交替布局的案例条，支持按类别筛选（全部 / AI 应用 / 数据可视化 / 全栈应用 / 小程序）
- **深浅色主题切换**：顶栏（移动端）与侧边栏（桌面端）均可切换，`localStorage` 记忆用户选择
- **导航高亮**：滚动监听自动高亮当前所在板块
- **响应式布局**：桌面端固定侧边栏，移动端顶部栏 + 抽屉菜单
- **留言表单**：前端本地校验（必填项与邮箱格式）
- **细节动效**：滚动浮现、图片悬停缩放等

## 技术栈

- HTML5 + CSS3（CSS 变量主题化、Flex/Grid 布局、媒体查询）
- 原生 JavaScript（无框架、无第三方库）
- SVG 插画资源

## 目录结构

```
lab04/
├── index.html          # 页面结构
├── css/
│   ├── base.css        # 主题变量 / 重置 / 基础样式（含浅色主题）
│   ├── layout.css      # 双栏布局与响应式切换
│   └── style.css       # 组件样式
├── js/
│   ├── projects.js     # 项目与分类数据
│   ├── render.js       # 案例渲染与筛选交互
│   └── nav.js          # 导航高亮 / 移动端菜单 / 主题切换
└── assets/images/      # 项目案例 SVG 插画
```

## 运行方式

纯静态页面，无需构建：

- 直接用浏览器打开 `index.html`；或
- 启动本地服务器后访问 `http://localhost:8123`：

```bash
python -m http.server 8123
```

兼容 Chrome / Edge 等现代浏览器及移动端浏览器。
